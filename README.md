# Self-Hosted-Linux-Server-with-a-Containerized-App
A Dockerized Node.js/Postgres app deployed on a self-managed Ubuntu server, built from scratch in VirtualBox — including real disk and networking troubleshooting along the way.
# Objective 
Building a linux serer from scratch using Virtual box and progressively building the system up over time. While incororating installions,remote administration,networking,containerization and deploying a apllication.
Along the way runing into problems with disk space failures,Networking Misconfigutaions and a partion table issue that required a full rebuild of the VM.

#Skills Learned 
instaliing and config a linux server (Ubuntu was the OS used) in a virtualized environtment 
config and securing remote access via SSH 
Resolving network configuration issues (NAT vs Bridged Adapter modes in VirtualBox)
Linux disk and partition management incluuding diagnosing a partially-resized partion 
Recognizing when to repair an environment versus rebuild it cleanly
installing and operating docker 
Writing a rest api and connecting it to postgreSQL database 
General Linux Command line proficiency(File operations,package management, systemd service management)

Orcale VirtualBox(Hypervisor) 
Ubuntu server 26.04 LTS(VM OS)
